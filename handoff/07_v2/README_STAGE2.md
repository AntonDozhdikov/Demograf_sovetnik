# ЭТАП II · КОНТРАКТ ПЕРЕДАЧИ ИССЛЕДОВАТЕЛЬСКОЙ БАЗЫ

Исходные массивы сегментов 01–06 сохраняются на прежних местах приватного GitHub.

1. dataset_index.json — полный каталог файлов с идентификаторами, адресами и SHA-256.
2. data_catalog.parquet — паспорт каждого сохранённого набора.
3. field_dictionary.parquet — все названия, типы и предполагаемая семантика полей.
4. temporal_profile.parquet — распределения по годам.
5. territorial_profile.parquet — наиболее частые территориальные значения.
6. indicator_profile.parquet — до 30 наиболее частых значений показателей на файл.
7. quality_profile.parquet — пропуски ключевых полей и проверки OD.
8. join_candidates.parquet — кандидаты на ключи объединения, НЕ валидированные соединения.
9. methodological_constraints.parquet — обязательные ограничения интерпретации.
10. issues.parquet — ошибки и проблемы.
11. handoff_summary.json — итог сквозного аудита.
12. stage2_loader.py — получение нужного исходного файла по каталогу и проверка SHA-256.

Вход следующего этапа: dataset_index.json + stage2_loader.py + секрет GITHUB_TOKEN.
Полные исходные данные повторно не публикуются.
Сумма строк разных наборов не является числом уникальных людей, организаций или территорий.
Каталог не является готовой ML-панелью: необходимо согласование показателей, территориальных уровней,
статистических единиц, времени и пересекающихся таблиц.
