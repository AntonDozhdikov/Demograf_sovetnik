## H1–H5 и публикационные границы
Исходные подтверждающие тесты V4: H1 — 2/12 статистически поддержаны, H2 — 1/12, H3 — не тестировалась из-за отсутствия валидного географического ключа. H4 описывает неоднородность территорий, H5 не подтверждена. В дополнительных **разведочных** проверках с фиксированным алгоритмом получены положительные сравнения при FDR <0.05 и положительном 95% ДИ: H1 — 21/72, H2 — 9/72; результаты не являются независимыми подтверждениями из-за множества близких протоколов и моделей. Данные — ретроспективный срез без подлинных исторических vintages; SHAP/абляции показывают прогнозные связи, не эффекты политики. Долгосрочные модели — рекурсивные, выбор DEV опирался на однолетнюю прокси-задачу.
